## [0.28.0] — 2026-07-27

### Fixed

- review, log: правки по пути вида `resources/views/vendor/…` больше
  не прячутся как шум. Фильтр «игнорируемых папок» срабатывал на
  любом сегменте пути, из-за чего опубликованные шаблоны пакетов
  Laravel — обычные исходники проекта под git — пропадали из дерева, а
  репозиторий, где это была единственная правка, выглядел чистым.
  Имена, которые артефакты сборки делят с исходниками (`vendor`,
  `dist`, `build`, `target`, `coverage`), теперь считаются шумом
  только в корне репозитория; однозначные (`node_modules`,
  `__pycache__`, `.idea`, …) по-прежнему скрыты на любой глубине.

### Changed

- session: кит, открытый из окна, где уже идёт сессия Claude, сразу
  встаёт на неё — открывается её проект, а курсор стоит на её строке,
  а не в начале списка. kitty отдаёт киту pid процесса окна под
  оверлеем, и сессия ищется по дереву процессов, поэтому в проекте с
  несколькими живыми сессиями выбирается именно нужная. Из обычного
  шелла всё как прежде: сессии текущего проекта либо список проектов.

## [0.27.0] — 2026-07-25

### Changed

- review, log: раскрытие свёрнутого блока в диффе (`Enter` или клик по
  разделителю) открывает по 50 строк за раз, а не весь блок целиком —
  под ним бывают сотни строк. Строки продолжают код над разделителем,
  то есть порядок чтения сохраняется; сам разделитель уезжает вниз
  ровно на столько же, а курсор и окно едут за ним — следующее
  нажатие приходится на то же место экрана. В разделителе видно,
  сколько строк ещё скрыто и сколько откроет следующее нажатие.
  Показать файл целиком по-прежнему можно режимами `a` (full-file) и
  `v` (final-view).

- review: go-to-definition (⌥+клик, `d`) больше не морозит интерфейс.
  Стоящий за ним repo-wide `git grep` выполнялся прямо в колбэке
  event loop, и на монорепозитории весь оверлей переставал
  перерисовываться — и читать Ctrl+C — на всё время поиска. Теперь
  поиск идёт в фоне, а в футере на это время появляется
  `searching for '<символ>'…`.

### Fixed

- все киты: быстрая прокрутка колесом (и зажатая стрелка) больше не
  подвешивает кит. Каждый щелчок колеса перерисовывал весь экран, и
  пачка событий выливала сотни килобайт escape-последовательностей в
  тот же терминал; на заполненном буфере stdout запись вставала, и
  кит переставал читать ввод. Теперь пачка сливается в один кадр —
  замер на 60 щелчках: было 60 кадров и 325 КБ, стало 1 кадр и 3 КБ,
  прокрутка при этом не теряется.

- все киты: опечатка в файле палитры больше не роняет кит. Роль,
  отсутствующая в *дефолтной* палитре, давала `KeyError` на импорте —
  одна удалённая строка в `config/palette/ghostty.conf` укладывала
  разом review, log и sessions. Теперь недостающая роль получает
  читаемый цвет, как и было обещано в документации.

- все киты: git больше не наследует терминал кита. Команда, спросившая
  пароль (удалёнка по HTTPS), перехватывала ввод TUI и подвешивала
  кадр; читающие команды вдобавок дрались с IDE за `index.lock`.
  Теперь git запускается с закрытым stdin, `GIT_TERMINAL_PROMPT=0` и
  `GIT_OPTIONAL_LOCKS=0`.

- review: go-to-definition выдавал сбой или таймаут git за уверенное
  «no definition for '<символ>'». Теперь показывается настоящая
  ошибка, а repo-wide поиск получил тот же увеличенный таймаут, что и
  Find in Files.

- review, log: поиск (`⌘f`) больше не показывает устаревшие совпадения
  после перестройки диффа — при изменении размера окна, горизонтальной
  прокрутке или смене вида панели.

- review: Find in Files больше не втягивает весь вывод `git grep` в
  память, чтобы потом обрезать его по потолку. На коротком запросе в
  большом репозитории это означало декодирование десятков мегабайт
  ради того, что всё равно уйдёт за лимит; теперь вывод читается
  по мере поступления и поиск обрывается на потолке.

- review: огромный untracked-файл больше не пересчитывается построчно
  при каждом скане, а бинарный файл больше не читается целиком до
  того, как его опознают бинарным.

- log: закрытие кита во время `fetch`/`push` больше не ждёт сети.
  Оверлей висел чёрным до 60/120 с, потому что фоновая работа шла на
  обычных потоках, которые Python join'ит на выходе.

- log: указатель мыши больше не сохраняет форму, взятую в диффе, после
  возврата к списку коммитов.

- sessions: вставка текста с управляющими байтами больше не срабатывает
  как ctrl-хоткеи в просмотре сессии.

- все киты: кэш проверки обновлений пишется атомарно и больше не
  теряет отметку «сегодня уже показывали», выставленную другим китом —
  из-за этого подсказка `brew upgrade` могла появиться дважды за сутки.

## [0.25.0] — 2026-07-24

### Changed

- terminal: `Cmd+Enter` (дефолтное новое окно kitty) снят — сплиты
  живут на `Cmd+D` / `Cmd+Shift+D`.

### Fixed

- terminal: сплиты (`Cmd+D`, `Cmd+Shift+D`) надёжно открываются в
  рабочей папке активного окна. Они полагались на `--cwd=current` —
  тот берёт cwd «самого нового» процесса окна, а рядом с Claude Code,
  постоянно плодящим короткоживущие процессы, это лотерея. Теперь
  используется `--cwd=last_reported`: сначала папка, о которой
  сообщило само окно, и откат на те же процессы, если отчёта не было.
  Табы (`Cmd+T`) — без изменений.

- session: сплиты из сессии claude (`Cmd+D`, `Cmd+Shift+D`)
  открываются в папке проекта. Кит открывал claude
  простым оверлеем, а для оверлеев kitty берёт рабочую папку из окна
  *под ним* — исходного шелла, обычно сидящего в домашней. Теперь
  сессия открывается как `overlay-main`: kitty считает такое окно
  настоящим при определении cwd; поведение «по выходу вернёшься в
  шелл» не изменилось. Вдобавок окно сообщает kitty свою папку при
  старте — его шелл сразу `exec`ается в claude, и prompt с отчётом не
  отрабатывает ни разу.

## [0.24.0] — 2026-07-20

### Added

- review: режим Find in Files на `Cmd+Shift+F` — поиск по всему
  проекту, как в IDE, доступен только внутри оверлея review (снаружи
  хоткей ничего не делает). Живой `git grep` по мере набора
  (smart-case, `x` переключает regex, видит untracked-файлы, уважает
  `.gitignore`, пропускает бинарники), дерево файлов со счётчиками
  совпадений, предпросмотр с подсветкой синтаксиса и навигацией по
  совпадениям `n`/`N` и `[`/`]`, `e` открывает редактор на совпадении,
  `⌘c` / `⌘⇧c` копируют код или ссылку `@путь#L42` для Claude Code.
  `Enter` на совпадении открывает файл штатной навигацией ревью:
  изменённый файл попадает в свой дифф со всем инструментарием
  (комментарии, stage), прочие — в тот же read-only вид, что и
  go-to-definition, `⌃o` возвращает. `Esc` возвращает в ревью ровно
  туда, где остановился.

- строка ввода во всех китах (поиск, фильтр, комментарий,
  переименование, …): каретку теперь можно двигать — `←`/`→`,
  `Home`/`End`, вставка, `Backspace` и прямой `Delete` в позиции
  каретки.

### Changed

- review/log: поиск по файлу переехал с `/` на `⌘f` (как в IDE); в
  списке коммитов log `⌘f` открывает фильтр. Внутри оверлеев глобальный
  `⌘f` (поиск по scrollback) пробрасывается киту.

## [0.21.0] — 2026-07-16

### Changed

- review: `Shift+клик` / `Shift+↑↓` в дереве файлов работают как классические
  GUI-списки — диапазон красится от неподвижного якоря (файла в фокусе при
  входе в мультивыбор), и повторное растягивание обратно к якорю снимает
  метки с ушедших из диапазона строк. `Shift+↑/↓` перескакивает строки без
  вклада в диапазон (развёрнутые папки) — пустых шагов нет. Точечное снятие
  метки с файла или папки — `⌥+клик`.
- review: при активном мультивыборе выделение показывают только метки;
  строка курсора без метки рисуется как обычная — так `⌥+клик` наглядно
  снимает выделение с текущего файла. Первый `⌥+клик` забирает в выборку и
  активный файл (как `⌘+клик` в GUI-списках) — получается два выделенных
  файла, а не переехавшая подсветка. Выделение в дереве не пустеет:
  `⌥+клик` по последней помеченной строке оставляет её помеченной (снятие —
  обычная навигация или Esc), и клики метками не переключают открытый дифф.

### Fixed

- review: `⌥+клик` по строке дерева больше не переносит курсор и не уводит
  фокус из диффа — только переключает метку, текущий просматриваемый файл
  остаётся выбранным.

## [0.20.0] — 2026-07-16

### Added

- review: **множественный выбор в дереве файлов.** `Shift+↑/↓` красит диапазон
  файлов от курсора; `Shift+клик` дотягивает выделение до кликнутой строки
  (как в GUI-списках — файл под курсором остаётся выделенным); `⌥+клик`
  точечно помечает/снимает файл или папку целиком, а `Shift+клик` по уже
  помеченной строке снимает метку. Диапазон помечает ровно
  то, что видно: развёрнутая папка сама не добавляет ничего (её файлы — свои
  строки), свёрнутая добавляет все свои файлы и подсвечивается сама.
  Помеченные строки выглядят
  как обычное выделение; обычная навигация (стрелки, клик, Home/End, `g`/`G`)
  или Esc снимает метки. `⌘c` копирует все помеченные пути как `@path`-
  упоминания, по одному на строку — готово для вставки в промпт Claude.
- конфиг терминала: **Shift+клик пробрасывается китам.** kitty обрабатывает
  `shift+left` сам, даже когда программа захватила мышь, — киты его не видели;
  `config/keys/mouse.conf` снимает эти grabbed-маппинги. Цена: внутри программ,
  захватывающих мышь (vim с мышью, htop), Shift+drag больше не запускает
  собственное выделение kitty — обычный шелл не затронут.

## [0.19.0] — 2026-07-15

### Added

- **Комментарии ревью — сразу в промпт Claude.** В `review` клавиша `s`
  собирает все комментарии в markdown — как `w`, — но вместо буфера обмена
  закрывает оверлей и вставляет текст прямо в окно, поверх которого он был
  открыт (там обычно ждёт Claude). Вставка bracketed, поэтому многострочное
  ревью ложится одним блоком и не отправляется переводами строк. `w`
  (копирование в буфер) работает как раньше.

### Changed

- **Esc на верхнем уровне теперь спрашивает перед закрытием.** В `log`,
  `review` и `session` Esc на дне каскада вместо тихого «ничего» показывает
  центрированный диалог в стиле kitty с кнопками Yes/No: `y`/`Enter` закрывает
  оверлей, `n`/`Esc` оставляет открытым, ←/→/Tab переключают кнопки, по кнопкам
  можно кликнуть (при наведении — курсор-рука). `q` и `⌃c` по-прежнему выходят
  сразу — `⌃c` работает даже при открытом диалоге.

## [0.18.0] — 2026-07-14

### Changed

- **Esc больше не закрывает оверлеи китов.** В `log`, `review` и `session` Esc
  по-прежнему ведёт по каскаду назад (выделение → поиск → фильтр → экран), но
  на верхнем уровне ничего не делает вместо выхода — случайный Esc не смахнёт
  оверлей. Выход — `q` или `⌃c`. Бонусом Esc на верхнем уровне `log` и `review`
  теперь сбрасывает применённый фильтр.

## [0.17.0] — 2026-07-14

## [0.14.0] — 2026-07-13

### Changed

- **Документация переехала в [GitHub wiki](https://github.com/DenoBY/familiar/wiki).**
  Папки `docs/` (страницы китов и скриншоты) больше нет ни в репозитории, ни в
  Homebrew-поставке; README ссылается на wiki. Wiki двуязычная (английские и русские
  страницы).

### Fixed

- **`⌃o` (возврат после прыжка к определению) работает на русской раскладке.**
  Терминальный конфиг мапит `ctrl+<кириллица>` в C0-байты (`send_text`), поэтому на
  ЙЦУКЕН сочетание приходит текстом, а не key-событием — просмотрщик review теперь
  разбирает эти байты для всех своих ctrl-шорткатов (`⌃o` назад, `⌃u`/`⌃d` скролл,
  `⌃w`/`⌃u` при наборе комментария).
- **Переход к определению стал быстрым на больших репозиториях.** Поиск определения
  теперь грепает только файлы языка клика (с fallback на repo-wide проход по
  исходникам), так что тяжёлые untracked-логи и минифицированные бандлы больше не
  подвешивают вьювер — на реальном Laravel-репозитории прыжок ускорился с ~3 с
  замершего UI до <0.1 с.

### Added

- **Переход к определению понимает синтаксис PHP и Ruby.** `$this->method()`,
  `Order::create()`, `?->`, `static::` и рубишный `Foo::Bar` теперь резолвят
  получателя: методы `$this`/`static` ищутся сперва в текущем файле, а вызов через
  импортированный класс (`use App\Models\Order; Order::create()`) прыгает сразу в
  файл этого класса. Тот же резолв получателя заработал для импортов Python
  (`mod.func`) и JS (`Api.get`); объявления PHP 8.1 `enum` распознаются.
- **Генератор демо-стенда** (`tools/demo_stand.py`): собирает демонстрационный
  git-репозиторий с фотогеничной историей, ветками и незакоммиченными правками плюс
  фейковое хранилище Claude Code с живыми сессиями — воспроизводимая сцена, чтобы
  переснимать скриншоты wiki после изменений UI.

## [0.13.0] — 2026-07-11

### Added

- **Переход к определению в просмотрщике review.** ⌥-клик по символу в диффе — или выделить
  слово и нажать `d` — прыгает к месту его объявления. Прыжок происходит внутри
  просмотрщика со стеком «назад» (`⌃o` — вернуться): определение в изменённом файле
  открывает его дифф, определение в неизменённом — открывается read-only. Если у символа
  несколько определений, их показывает пикер (`1`–`9` или клик). Резолв учитывает контекст:
  `obj.name` предпочитает методы, `name(` — объявления, а импортнутые имена ведут в точный
  файл по импортам текущего файла (Python `from a.b import x` и относительные `.`/`..`;
  JS/TS `import`/`require` с расширениями и `index`; PHP `use` через composer PSR-4; символы
  Go-пакетов через `go.mod`). Всё прочее — repo-wide `git grep`, включая новые
  untracked-файлы, без индекса и языкового сервера. ⌘-клик невозможен: мышиный протокол
  терминала несёт только Shift/Alt/Ctrl, но не Cmd, поэтому триггер — ⌥-клик.
- **Мышиные жесты в диффе review.** Двойной клик по слову выделяет именно слово (для
  копирования), а клик по номеру строки ставит к ней комментарий — хоткей `c`/Enter тоже
  работает. Указатель превращается в руку над номерами строк и, пока зажат ⌥, над
  идентификаторами, к которым можно перейти. Выделение текста теперь сохраняет подсветку
  синтаксиса, добавляя только фон.

- session: заголовки сессий и диффы читаются как UTF-8 независимо от
  локали; переименование сессии безопасно при не-ASCII содержимом.
- `familiar disable --restore` восстанавливает kitty.conf из `.bak` и при
  уже снятом managed-блоке.
- Конфликтующие комбинации `familiar enable` (`--all` с именами или
  `--kittens`) — ошибка вместо молчаливого игнорирования.
- Запись kitty.conf стала атомарной (temp-файл + `os.replace`).
- `familiar status` определяет терминал-режим по точной строке `include`.
