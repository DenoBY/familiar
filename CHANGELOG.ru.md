## [0.34.0] — 2026-09-04

### Added

- review, log: папка с несколькими независимыми репозиториями больше не тупик.
  Открытый из `~/Projects/yr` кит отвечал `not a git repository`, потому что оба
  спрашивали у git корень текущей папки и не получали ничего. Теперь они
  сканируют папку на два уровня вглубь и работают со всем, что нашли.
- review: репозитории стали верхним уровнем дерева — у каждого своя ветка,
  число файлов и собственные `+N −M`. Индексация, откат, диффы, комментарии и
  метки адресуют тот репозиторий, которому принадлежит файл, поэтому два файла
  с одинаковым относительным путём в разных репозиториях больше не путаются
  между собой. Скопированные `@path` несут префикс репозитория
  (`@api/src/main.go`) — именно по нему Claude Code откроет файл из папки,
  в которой запущен кит.
- log: коммиты всех репозиториев сливаются в одну ленту по времени, имя
  репозитория и возраст коммита — отдельными колонками. Докрутка вниз только
  удлиняет список: репозиторий, догруженный до какой-то даты, не вставит более
  старые коммиты в уже прочитанное. `f` фетчит все репозитории разом и называет
  те, где не вышло; `p` по-прежнему пушит один — тот, которому принадлежит
  выбранный коммит.
- review: `b` сравнивает рабочее дерево с веткой, от которой вы отошли, — вся
  работа ветки, и уже закоммиченная, и ещё нет, читается одним диффом. База —
  `origin/HEAD`, иначе `main`/`master`/`develop`; на самой базовой ветке кит
  говорит, что сравнивать не с чем. В папке с репозиториями у каждого своя база,
  а те, что сидят на ней, по-прежнему показывают рабочее дерево. Индексация и
  откат на время сравнения придержаны — `b` возвращает к рабочему дереву.
- review, log: `R` наводит фокус на один репозиторий — дерево схлопывается до
  него, лента сужается до его коммитов, возвращается граф веток (поверх
  репозиториев общей истории не существует). `Esc` снимает фокус, `0` в меню
  возвращает все. В обычном репозитории `R` по-прежнему означает refresh.
- review: Find in Files ищет по всем репозиториям в поле зрения, у каждого свой
  бюджет совпадений — иначе один шумный репозиторий выбрал бы весь потолок.
  Go-to-definition поднимает языковой сервер на репозиторий, лениво — только для
  тех, чьи файлы действительно открывали.

### Fixed

- review, log: `<?php` больше не сер, как комментарий. У Pygments этот тег лежит
  в ветке `Comment` (там же `#include` и `#define` в C), и цвет комментария читался
  как «строка ничего не делает» — теперь такие строки красятся как код, которым и
  являются.
- log: панель подробностей больше не выталкивает шапку за экран. У merge-коммита,
  сделанного с конфликтами, в теле сообщения есть табы (`# Conflicts:`), а таб —
  это один символ при подсчёте и восемь колонок при отрисовке: строка панели
  вылезала за край, кадр становился выше окна и уезжал вверх вместе с шапкой,
  оставляя внизу хвост перенесённой строки. Табы теперь разворачиваются в четыре
  пробела — как это давно делает дифф.
- ошибки git теперь свои у каждого потока. Фоновый `fetch` мог затереть ошибку
  команды главного потока, и причина пустого списка показывалась чужая. Скан
  каждого репозитория выносит свою ошибку из потока наружу, поэтому папка чистых
  репозиториев говорит «no changes», а не показывает застрявшее
  `not a git repository` от пробы самой папки.

## [0.33.0] — 2026-08-27

### Changed

- review, log: go-to-definition спрашивает языковой сервер, а не грепает
  репозиторий. `git grep` видел только отслеживаемые git файлы, поэтому метода,
  объявленного в `vendor/` или `node_modules/` — во всём, что скрыто
  `.gitignore`, — для него просто не существовало. И наследование ему не по
  зубам: `$this->belongsTo(...)` объявлен в трейте несколькими классами выше, а
  `->withTrashed()` следом требует знать тип, который вернул предыдущий вызов.
  Сервер знает и то, и другое.
- review, log: определение за пределами репозитория (класс фреймворка в
  `vendor/`, модуль стандартной библиотеки) открывается read-only по
  абсолютному пути; `⌃o` возвращает назад, как и раньше.
- log: при просмотре коммита резолв идёт по рабочей версии файла — именно её
  сервер и проиндексировал, а снимок с экрана ему не показывают, чтобы не
  испортить кэш. Рабочее дерево обычно ушло вперёд, поэтому поиск начинается со
  строки, по которой кликнули, и берёт ближайшее к ней вхождение, а не первое в
  файле (им почти всегда оказывается импорт). Если файла в рабочем дереве уже
  нет, работает поиск по символам проекта.
- log: прыжок в файл, которого в коммите нет — всё, что лежит в `vendor/` или
  иначе скрыто от git, — показывает его с диска, а не пустую панель.
- review, log: `⌃u` / `⌃d` больше не скроллят дифф на полстраницы, а `⌃d` больше
  не выходит из log на экране списка коммитов. `⌃d` в терминале — «конец ввода», и
  случайное нажатие стоило экрана ненаписанных замечаний; вне строки ввода обе
  клавиши теперь молчат, а в ней `⌃u` по-прежнему стирает текст. Скроллят
  `PgUp` / `PgDn` и стрелки.

### Added

- `familiar lsp` — `status` (что настроено и что найдено, плюс готовый блок
  реестра для языка, которого в нём нет), `install ЯЗЫК`, `warm ЯЗЫК`
  (проиндексировать проект заранее, с живым прогрессом) и `clean` (снести кэш
  индексов, не трогая сами серверы).
- Реестр языков в `config/lsp.conf`, из коробки на 27 языков. Он сливает три
  уровня — встроенный, `~/.config/familiar/lsp.conf` и
  `<репо>/.familiar/lsp.conf`, — поэтому язык добавляется, заменяется или
  выключается правкой блока, без единой строки Python. Файлы без расширения (`bin/familiar`,
  git-хуки) опознаются по shebang.
- Пока сервер индексирует, в футере видно, как идёт работа: проценты, если
  сервер их сообщает, иначе прошедшее время и рост кэша индекса. Индикатор
  стоит в начале строки и своим цветом — в сером ряду подсказок его не
  замечали, — и первую секунду не показывается вовсе, чтобы тёплый старт им
  не мигал.
- Пикер больше не показывает неточные совпадения имени, когда есть точные.
  Раньше клик по классу предлагал выбрать между ним самим и тем, что нечётко
  совпало в стабах сервера; теперь единственное настоящее определение
  открывается сразу. Перегрузки, объявленные подряд (шесть `@overload` для
  `getattr` в typeshed), считаются одной целью; стаб (`.pyi`, `.d.ts`)
  отбрасывается, если среди ответов есть настоящий исходник модуля; длинные
  пути ужимаются в середине, чтобы строка кода не уезжала за край. Цифра, за
  которой кандидата нет, список не трогает — закрывают его клик мимо и `Esc`.
- `familiar enable review` (или `log`) предлагает поставить недостающие серверы;
  `--no-lsp` отключает предложение.
- Серверы запускаются с `PATH`, дополненным обычными путями homebrew и
  тулчейнов. kitty, запущенная из Dock, наследует голый системный `PATH`, а
  серверы из npm — это скрипты `#!/usr/bin/env node`: без этого они умирали, не
  сказав ни слова.

### Removed

- Резолвер на grep. Языки, для которых сервер не настроен, больше не получают
  грубый поиск по ключевым словам, который раньше работал как запасной путь —
  `familiar lsp status ЯЗЫК` печатает блок, чтобы такой язык добавить.

### Fixed

- restore: снимок, снятый при открытом ките, больше не рассыпает сплиты при
  следующем запуске. Кит открывается во весь таб через `goto_layout stack`, а
  такой таб kitty сериализует как stack — дерева сплитов в снимке нет вовсе,
  возвращать было нечего, и окна приезжали одной линией. Теперь watcher
  откладывает снимок, пока layout не вернётся; выход по `Cmd+Q` снимок делает
  по-прежнему — кит возвращает layout до записи.

## [0.32.2] — 2026-08-18

### Fixed

- close: после подтверждения `Cmd+W` на месте сессии Claude Code не остаётся
  пустая панель. Кит session открывает сессию оверлеем над шеллом, из которого

## [0.32.1] — 2026-08-17

### Fixed

- close: `Cmd+W` больше не отвечает на собственный вопрос. Подтверждение —
  оверлей, а в оверлее кита `Cmd+W` шлёт `⌃c`, поэтому клавиша, которой
  вопрос позвали, вторым нажатием его же и отменяла. Пока вопрос на
  экране, она игнорируется; отменяют `esc`, `n`, `Ctrl+C` и кнопка `No`.
- close: маппинг из 0.32.0 молча отключил защиту от стопки вопросов по
  `Cmd+W`. Свой вопрос kitty всё ещё рисует китом `ask` — для
  `confirm_os_window_close`, — и внутри него `Cmd+W` открывал сверху
  вопрос про панель, объявляя работающим в ней `kitten ask --type=yesno`.
  Гард повторён после маппинга кита, где снова выигрывает.
- close: вопрос помещается в панель, в которой нарисован. В сплите на
  шесть строк сначала уходят пустые разделители, затем рамки кнопок
  сжимаются до `[ Yes ] [ No ]`, и последней отбрасывается подсказка —
  раньше диалог целиком уезжал скроллом. В узкой панели зазор между
  кнопками жмётся до одного пробела, а не переносятся их рамки.
- Вставка в вопрос больше не отвечает за пользователя: буфер, начинающийся
  с `y`, сам закрывал панель (или kitty).

## [0.31.0] — 2026-08-15

### Added

- restore: kitty запоминает открытые окна и возвращает их. Снимок всех
  OS-окон, табов, сплитов, layout'ов и рабочих папок делается в фоне,
  при закрытии окна и при выходе; восстанавливается при следующем
  запуске и в любой момент по `⌘⇧T` (последний снимок переживает и
  закрытие всех окон — на macOS сама kitty при этом остаётся жить).
  Таб, где работал `claude`, поднимается как `claude --resume <та
  самая сессия>`, с перепиской на экране. Таб с интерактивной
  программой из безопасного списка (`nvim`, `htop`, `lazygit`,
  `less`, …) запускает её заново; остальные табы возвращаются с
  шеллом, своей папкой и прежним содержимым экрана. Ничего другого не
  перезапускается — случайно попавший в снимок `rm` не выполнится.
  Хранятся десять снимков, а неизменившийся терминал повторно на диск
  не пишется — фоновый таймер ничего не стоит, пока вас нет;
  `familiar disable` сообщает, где остались снимки, потому что в них
  лежит вывод терминала. Включается `familiar enable --all` или
  `--restore-session`, выключается `--no-restore-session`.
- quit: `⌘Q` спрашивает на весь таб, а не встроенным вопросом kitty —
  тот рисуется поверх активного окна и в сплите выходит размером со
  сплит, хотя закрывает всё. Экран показывает, какие сессии Claude
  Code сейчас идут, и снимает состояние окон перед выходом, чтобы не
  потерялось сделанное после последнего фонового снимка. Кнопки
  `Yes`/`No` — те же, что уже есть у китов: стрелки/`tab`/клик
  выбирают, `enter` жмёт; `y` выходит сразу, `esc`/`n`/`Ctrl+C`
  отменяют и возвращают layout. Ставится вместе со снимками окон.
- terminal: закрытие теперь спрашивает, прежде чем что-то потерять, —
  OS-окно с несколькими табами просит подтверждения, а `⌘W`
  переспрашивает, когда в панели что-то запущено (панель на промпте
  шелла по-прежнему закрывается одним нажатием).

## [0.30.0] — 2026-08-10

### Added

- log: открытый коммит теперь показывается полноценным экраном ревью —
  тем же, каким `review` показывает незакоммиченные правки. Работают
  комментарии к строкам (`c`, `{`/`}`, `w` — выгрузить, `s` — отправить
  Claude), go-to-definition (`⌥`+клик, `d`, `⌃o` назад), Find in Files
  (`⌘⇧F`), метки файлов (`⇧↑↓`, `⇧`/`⌥`+клик), фильтр дерева (`f`),
  открытие в редакторе (`e`) и полустраничный скролл `⌃u`/`⌃d`.
  Определения и результаты поиска берутся из снимка коммита, поэтому
  совпадают с кодом, который показывает дифф, а не с рабочим деревом.

### Fixed

- review, log: курсор больше не пропадает под нижним краем панели
  диффа. Липкий заголовок скоупа (`▸ def …`) занимает строку, а
  навигация считала панель на строку выше — из-за этого шаг вниз
  стрелками, `[`/`]` и прокрутка ставили курсор на неотрисованную
  строку.
- review, log: `[`/`]` показывает ханк с несколькими строками контекста
  сверху, а не вплотную к краю панели, и, нажатый в дереве файлов,
  переводит фокус в дифф — иначе курсора не видно.

## [0.28.0] — 2026-07-27

### Fixed

- review, log: правки по пути вида `resources/views/vendor/…` больше
  не прячутся как шум. Фильтр «игнорируемых папок» срабатывал на
  любом сегменте пути, из-за чего опубликованные шаблоны пакетов
  Laravel — обычные исходники проекта под git — пропадали из дерева, а
  репозиторий, где это была единственная правка, выглядел чистым.
  Имена, которые артефакты сборки делят с исходниками (`vendor`,
  `dist`, `build`, `target`, `coverage`), теперь считаются шумом
  только в корне репозитория; однозначные (`node_modules`,
  `__pycache__`, `.idea`, …) по-прежнему скрыты на любой глубине.

### Changed

- session: кит, открытый из окна, где уже идёт сессия Claude, сразу
  встаёт на неё — открывается её проект, а курсор стоит на её строке,
  а не в начале списка. kitty отдаёт киту pid процесса окна под
  оверлеем, и сессия ищется по дереву процессов, поэтому в проекте с
